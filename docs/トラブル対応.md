# 学祭カジノ トラブル対応シート（机に置く用）

管理画面：PC-A で `http://localhost:3000/admin`　／　パスワード：＿＿＿＿＿＿＿＿＿＿

| 症状 | まずやること | だめなら |
|---|---|---|
| ゲーム画面に「サーバーに接続中…」 | PC-A の黒い画面（サーバー）が開いているか確認。閉じていたら `start-server.bat` | PC-B なら Wi-Fi がカジノ用ルーターにつながっているか確認 → PC-A のIPが変わっていないか（黒い画面に表示）→ `start-game.bat` の SERVER を直す |
| パスワードを忘れた | 管理画面で名前を検索 → 本人確認（最近遊んだゲーム・チップ数など）→「パスワードを再設定」して本人に伝える | — |
| 名前を忘れた | 管理画面の一覧から一部の文字で検索 | 見つからなければ新しく登録してもらう |
| 「すでに使われています」で登録できない | 別の名前（数字や記号を足す）にしてもらう | 本人の登録済みなら「つづきから」へ |
| 「何度も間違えたので○秒待って」 | 1分待つ | 管理画面でパスワードを再設定 |
| スマホでゲーム画面が開かない | スマホが会場Wi-Fiにつながっているか、URL（ランキング画面の下に表示）が合っているか確認 | モバイルデータをオフにしてもらう。ルーターのAP分離（プライバシーセパレーター）をオフ |
| 「別の端末でプレイ中です」 | 前の端末で「おわる」を押す。または90秒待つ | 管理画面で名前を検索して「ロック解除」 |
| チップが0で遊べない | ログインすると「最初からやり直す」ボタンが出るので押してもらう（最高記録は残る） | — |
| VRボーナスを付け忘れた／二重に付けた | 管理画面で名前を検索して「VRボーナス」 | 二重なら履歴の「取消」 |
| チップがおかしい・誤操作 | 管理画面の履歴で確認し「取消」 | 「増減する」「この値に設定」で修正（メモ欄に理由を書く） |
| 変な名前 | 管理画面で「名前変更」 | — |
| 画面が固まった | F5 で再読み込み（プレイ中のゲームは負け扱いになることがある） | Alt+F4 → `start-game.bat` |
| サーバーの黒い画面にエラー | 5秒後に自動で再起動するので待つ | 黒い画面を閉じて `start-server.bat`。「ポートは使用中」なら既に起動しているので何もしない |
| PCがスリープした | 電源ボタンで復帰。サーバーは復帰後そのまま動く | 黒い画面が無ければ `start-server.bat` |
| DBが壊れた・消えた | **サーバーを止める** → `data/backups/` の一番新しい `.db` を `data/casino.db` に上書き（`casino.db-wal` `casino.db-shm` は削除）→ 再起動 | USBメモリのバックアップから同様に復元 |

## 毎日の終わりに

1. USBメモリを挿して `backup-to-usb.bat` → ドライブ文字（例 `E`）を入力
2. ゲーム端末は Alt+F4、サーバーの黒い画面は閉じる（閉じる前に自動バックアップあり）
