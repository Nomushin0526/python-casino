# 学祭カジノ（情報技術部 学祭展示 2026/11/7・8）

QRコード付きカードでチップを管理し、ノートPC上のミニゲームで遊ぶ展示用システムです。
チップは2日間通しでSQLiteに保存し、最高到達チップ数でランキングを表示します。

- チップに換金性はなく、景品交換もしません。個人情報は扱いません（ニックネームのみ）
- 画像・音源は使っていません（トランプ・花札はCSSで自作、効果音はWebAudioで合成）
- 外部CDNは使いません。ブラウザ用ライブラリ（Matter.js / jsQR）は `public/vendor/` に同梱済み

| 画面 | URL |
|---|---|
| ゲーム端末 | `http://<PC-AのIP>:3000/?terminal=PC-B` |
| ランキング（別モニター） | `http://<PC-AのIP>:3000/ranking` |
| 管理画面 | `http://localhost:3000/admin` |
| QRカード印刷 | 管理画面 →「QRカード印刷」 |

## 遊べるゲーム

| ゲーム | 結果倍率 | 補足 |
|---|---|---|
| レバレッジピンボール（目玉） | 目標未達 −1 / 目標達成 +1 / 高得点 +2 / 超高得点 +3 | 3球×30秒。Z と / でフリッパー、スペース長押しで発射（マウスの左右クリックでも可） |
| ブラックジャック | 勝ち +1 / BJ +1.5 / 引分 0 / 負け −1 | 6デッキ毎回シャッフル。ディーラー17以上でスタンド。ダブルダウンは倍率2倍 |
| バカラ | P +1 / B +0.95 / タイ +8 / 外れ −1 | 標準の3枚目ルール |
| テキサスホールデム | 持ち込みチップの増減 × レバレッジ | CPU3人、5ハンド。役判定は単体テストあり |
| 大富豪 | 大富豪 +2 / 富豪 +1 / 貧民 −1 / 大貧民 −2 | CPU3人、1ゲーム。革命・8切りあり。開始前にルール表示 |
| 花札（こいこい） | 大勝 +2 / 勝ち +1 / 引分 0 / 負け −1 | CPU相手に3か月。開始前・プレイ中に役一覧を表示可 |

**チップ増減 = 賭けチップ × 結果倍率 × レバレッジ**（勝ちは小数切り捨て、負けは所持チップまで）。
0になると「ロスカット」演出で終了します。

## 準備（事前に1回）

1. **Node.js 22.13 以上**（LTS版の 22 か 24）を PC-A にインストール
   https://nodejs.org/ （DBは Node.js 標準の `node:sqlite` を使うので、ネイティブモジュールのビルドは不要）
2. このフォルダを PC-A にコピー
3. インターネットにつながる状態で一度 `start-server.bat` をダブルクリック（自動で `npm install` されます）
   - 手動なら `npm install`
4. `config.local.json` を作り、**管理パスワード**と**カード用secret**を変更する（Git管理外のファイル）
   ```json
   {
     "admin": { "password": "当日だけのパスワード" },
     "card": { "secret": "ランダムな長い文字列" }
   }
   ```
   > ⚠ `card.secret` はQRカードの確認コードの元です。**カードを印刷した後に変更するとカードが使えなくなります。**
5. 管理画面 →「QRカード印刷」で必要枚数を印刷（A4に10枚、名刺サイズ）
6. 管理画面 →「バックアップ / リセット」で、テストプレイのデータを本番前に削除

PC-B はブラウザ（Chrome か Edge）があればOK。Node.js は不要です。

## 当日の起動手順

| PC | やること |
|---|---|
| PC-A（サーバー兼ゲーム機） | ① `start-server.bat` をダブルクリック（黒い画面は閉じない） ② `start-game.bat` をダブルクリック ③ 必要なら `start-ranking.bat` |
| PC-B（ゲーム機） | `start-game.bat` を開いて `SERVER=` を PC-A のアドレス、`TERMINAL=PC-B` に書き換えてからダブルクリック |

- PC-A のIPアドレスは、サーバー起動時の黒い画面に「他のPCから : http://192.168.x.x:3000/」と表示されます
- ゲーム端末はキオスク（全画面）モードで開きます。**終了は Alt + F4**
- Mac / Linux でサーバーを動かす場合は `start-server.command`

### 別PC（PC-B）でカメラを使う設定について

ブラウザは「http://IPアドレス」の接続ではカメラを使わせてくれません。
`start-game.bat` は Chrome/Edge を `--unsafely-treat-insecure-origin-as-secure=<SERVER>` 付きで起動するので、そのままでカメラが使えます。
（手動で設定する場合は `chrome://flags/#unsafely-treat-insecure-origin-as-secure` に `http://192.168.x.x:3000` を登録して再起動）

カメラが使えない場合も、待機画面の入力欄にカードの文字（例 `P0001-ABCD`）を打てばログインできます。
USB接続のバーコードリーダー（キーボード入力型）もこの欄で使えます。

## 運用

- **VRボーナス**：VR体験後に管理画面でカードを読み取り「VRボーナス +50」（1人1日1回）
- **復活**：チップ0の人に受付で「復活 +50」（1人1日1回）
- **残高修正**：「増減する」「この値に設定」。履歴の「取消」で誤操作を打ち消せます（取消も履歴に残ります）
- **二重利用防止**：同じカードは2台で同時に使えません。端末を放置した場合は90秒で自動解除、急ぐときは管理画面の「ロック解除」
- **無操作タイムアウト**：90秒操作がないと待機画面に戻ります（ゲーム中だった場合は「負け」扱い）
- **ロスカット**：所持チップが0になると発動。最高記録はランキングに残ります
- **かんたんモード**：子ども向け。レバレッジ×1固定（登録時・ゲーム選択画面・管理画面で切替）

### バックアップ

- サーバーは10分ごとに `data/backups/` へ自動バックアップ（最新50個を保持）
- **各日の終了時**：USBメモリを挿して `backup-to-usb.bat` をダブルクリック → ドライブ文字を入力
  （または管理画面 →「DBファイルをダウンロード」）
- 復元：サーバーを止め、バックアップの `.db` を `data/casino.db` に上書き（`casino.db-wal` / `casino.db-shm` があれば削除）して再起動

## 設定（config.json）

数値はすべて `config.json` で変更できます（変更後はサーバー再起動）。当日用の上書きは `config.local.json` に同じ形で書きます。

| 項目 | 場所 |
|---|---|
| 初期チップ・最低賭け額・レバレッジ・VRボーナス・復活 | `chips` |
| 無操作タイムアウト・端末ロック解除時間 | `session` |
| ピンボールの目標スコア・倍率・キー割り当て | `games.pinball` |
| 各ゲームの倍率・デッキ数・ハンド数など | `games.*` |
| ゲームの公開/非公開 | `games.*.enabled` |
| NGワード | `ngWords` |

### ピンボールの目標スコア調整

初期値は「目標 1,500 / 高得点 3,500 / 超高得点 6,000」です。テストプレイ後に調整してください。
台の物理とスコア分布はシミュレーションで確認できます：

```sh
node scripts/pinball-sim.js 40   # 自動でフリッパーを動かすボットに遊ばせてスコア分布を表示
node scripts/pinball-check.js    # 発射とフリッパーの基本動作チェック
```

## ルールの細かい決め

仕様書で決まっていない部分は次のようにしています（必要なら config やコードで変更）。

- **QRの中身**：`P0001-ABCD`（ID＋確認コード）。IDだけのQRを自作されても使えません（管理画面ではIDだけでも検索可）
- **途中終了**：ゲーム中に無操作タイムアウト・端末の切り替えがあった場合、そのゲームは「−1（負け）」で精算
- **賭け額**：最低10チップ。所持チップが10未満のときは全額まで賭けられる
- **ブラックジャック**：ダブルダウンは倍率×2（負けも×2）。配られた時点で両者のBJを判定。スプリット・サレンダー・インシュランスなし
- **バカラ**：プレイヤー/バンカーに賭けてタイになった場合は**引き分け（±0）**（実際のカジノと同じ）。
  仕様書どおり「外れ −1」にするなら `games.baccarat.tiePushesPlayerBanker` を `false`
- **ホールデム**：バイイン＝賭けチップ、CPUも同額。ブラインドは賭けチップの5%/10%。CPUはモンテカルロで勝率を見積もって判断
- **大富豪**：ジョーカー1枚（他の数字の代わりにもなる）。階段・しばり・スペ3返し・都落ちなどのローカルルールなし。あなたの順位が決まった時点で終了
- **こいこい**：こいこい後に相手があがると相手の点が2倍。流局は0点。親は月ごとに交代
- **制限時間**：ブラックジャック・ホールデム・大富豪・こいこいは1手ごとに制限時間（時間切れは自動で無難な手）

## 開発

```sh
npm install
npm start        # http://localhost:3000
npm test         # API・役判定・各ゲームのルールの単体テスト
npm run vendor   # node_modules から public/vendor にライブラリをコピーし直す
```

```
server/          Express サーバー（app.js がAPI、db.js がSQLite、codes.js がQRコード）
public/          ブラウザ側（index.html ゲーム端末 / admin.html 管理 / ranking.html / cards.html）
  js/lib/        ゲームのルール（サーバー・テストと共通）
  js/games/      各ゲームの画面
  vendor/        Matter.js・jsQR（ローカル同梱）
scripts/         バックアップ・ピンボール調整用
test/            node:test の単体テスト
docs/            当日用の資料
```

- チップの増減はすべてサーバーで計算し、`transactions` テーブルに記録します。ブラウザからは「ゲーム結果」（スコアや勝敗）だけを送ります
