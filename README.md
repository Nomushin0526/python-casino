# 学祭カジノ（情報技術部 学祭展示 2026/11/7・8）

来場者が名前とパスワードで登録し、チップを使ってノートPC上のミニゲームで遊ぶ展示用システムです。
チップは2日間通しでSQLiteに保存し、最高到達チップ数でランキングを表示します。

- チップに換金性はなく、景品交換もしません。個人情報は扱いません（ニックネームのみ）
- 画像・音源ファイルは使っていません。トランプ・花札・背景・電飾・コインなどの演出はすべて CSS / SVG / Canvas で自作、効果音は WebAudio で合成しているので、著作権の心配がなくオフラインでも動きます
- 外部CDNは使いません。ブラウザ用ライブラリ（Matter.js）は `public/vendor/` に同梱済み

| 画面 | URL |
|---|---|
| ゲーム端末 | `http://<PC-AのIP>:3000/?terminal=PC-B` |
| ランキング（別モニター） | `http://<PC-AのIP>:3000/ranking` |
| 管理画面 | `http://localhost:3000/admin` |

## 遊べるゲーム

| ゲーム | 結果倍率 | 補足 |
|---|---|---|
| レバレッジピンボール（目玉） | 目標未達 −1 / 目標達成 +1 / 高得点 +2 / 超高得点 +3 | 3球×30秒。Z と / でフリッパー、スペース長押しで発射、プレイ中のスペースで「台をゆらす」 |
| ブラックジャック | 勝ち +1 / BJ +1.5 / 引分 0 / 負け −1 | 6デッキ毎回シャッフル。ディーラー17以上でスタンド。ダブルダウンは倍率2倍 |
| バカラ | P +1 / B +0.95 / タイ +8 / 外れ −1 | 標準の3枚目ルール |
| テキサスホールデム | 持ち込みチップの増減 × レバレッジ | CPU3人、5ハンド。役判定は単体テストあり |
| 大富豪 | 大富豪 +2 / 富豪 +1 / 貧民 −1 / 大貧民 −2 | CPU3人、1ゲーム。開始前にローカルルールを選べる |
| 花札（こいこい） | 大勝 +2 / 勝ち +1 / 引分 0 / 負け −1 | CPU相手に3か月。開始前・プレイ中に役一覧を表示可 |

**チップ増減 = 賭けチップ × 結果倍率 × レバレッジ**（勝ちは小数切り捨て、負けは所持チップまで）。
0になると「ロスカット」演出のあと、「最初からやり直す」で初期チップから再スタートできます（最高記録はランキングに残ります）。

カードゲームはすべて、画面右側に**カードの絵つきの早見表**（役の強さ・カードの数え方・ローカルルールなど）を常に表示します。
プレイ中も上の「📖 ルール」ボタンでいつでもルールを見返せます。ボタンや表示は「降りる」「同額を出す」「もう1枚引く」のように初心者向けの言葉にしています。

## 準備（事前に1回）

1. **Node.js 22.13 以上**（LTS版の 22 か 24）を PC-A にインストール
   https://nodejs.org/ （DBは Node.js 標準の `node:sqlite` を使うので、ネイティブモジュールのビルドは不要）
2. このフォルダを PC-A にコピー
3. インターネットにつながる状態で一度 `start-server.bat` をダブルクリック（自動で `npm install` されます）
   - 手動なら `npm install`
4. `config.local.json` を作り、**管理パスワード**を変更する（Git管理外のファイル）
   ```json
   {
     "admin": { "password": "当日だけのパスワード" }
   }
   ```
5. 管理画面 →「バックアップ / リセット」で、テストプレイのデータを本番前に削除

PC-B はブラウザ（Chrome か Edge）があればOK。Node.js は不要です。

## 当日の起動手順

| PC | やること |
|---|---|
| PC-A（サーバー兼ゲーム機） | ① `start-server.bat` をダブルクリック（黒い画面は閉じない） ② `start-game.bat` をダブルクリック ③ 必要なら `start-ranking.bat` |
| PC-B（ゲーム機） | `start-game.bat` を開いて `SERVER=` を PC-A のアドレス、`TERMINAL=PC-B` に書き換えてからダブルクリック |

- PC-A のIPアドレスは、サーバー起動時の黒い画面に「他のPCから : http://192.168.x.x:3000/」と表示されます
- ゲーム端末はキオスク（全画面）モードで開きます。**終了は Alt + F4**
- Mac の場合は `start-server.command` / `start-game.command` / `start-ranking.command` / `backup-to-usb.command`
  （Chrome が必要。キオスクの終了は ⌘Q。初回は右クリック →「開く」）

### 遊び方の流れ（来場者）

1. トップ画面で「はじめて」→ 名前とパスワードを決めて登録（初期チップがもらえる）
   - 同じ名前でも登録できます（ログインは名前＋パスワードで区別）。ただし「同じ名前＋同じパスワード」は区別できないので登録できません
   - 同じ名前を禁止したいときは `config.json` の `account.allowDuplicateNames` を `false` に
   - 全角/半角・大文字/小文字・空白の違いは同じ名前とみなします
2. 2回目からは「つづきから」→ 名前とパスワードでログイン
3. パスワードを忘れた人は受付へ（管理画面で名前を検索 →「パスワードを再設定」）

ランキングには登録した名前が表示されます。

### スマホで遊ぶ

来場者のスマホでも遊べます（画面はスマホ向けに自動で切り替わります）。

1. スマホを会場のWi-Fi（PC-A と同じルーター）につなぐ
2. ブラウザで `http://<PC-AのIP>:3000/` を開く（ランキング画面の下にも表示されます）
3. あとはPCと同じ。カードゲームの早見表は右下の「📖 早見表」ボタンで開きます

- ピンボールは **画面の左半分をタップ＝左フリッパー、右半分＝右フリッパー**、発射は画面を長押しして離す、「ゆらす」ボタンで台をゆらせます
- インターネットにつながらないWi-Fiだと、スマホが「インターネット未接続」と出してモバイル通信に切り替えることがあります。そのときは「このまま接続」を選ぶか、モバイルデータをオフにしてもらってください
- ルーターの「プライバシーセパレーター／AP分離」がオンだと、スマホからPC-Aに接続できません。オフにしてください

## ネット公開版（Cloudflare Pages）

会場Wi-Fiが使えない場合は、Cloudflare Pages（無料）でネットに公開します。来場者は自分のスマホの回線で URL を開くだけで遊べます。
ゲーム画面・管理画面・ランキングは PC版とまったく同じです（サーバー部分だけ Cloudflare の Pages Functions と D1 データベースで動きます）。

### 初回セットアップ（Macのターミナルで）

1. Cloudflare のアカウントを作る（無料）：https://dash.cloudflare.com/sign-up
2. ターミナルで：
   ```
   cd ~/Desktop/casino
   git pull
   npm install
   npm run cf:setup
   ```
   - ブラウザが開いたら Cloudflare にログインして「Allow（許可）」を押す
   - 「Enter a secret value:」と出たら、**管理画面のパスワード**を入力して Enter（文字は表示されません）
3. 最後に表示される `https://it-casino.pages.dev/`（または似たURL）が公開URLです
   - 管理画面：`https://it-casino.pages.dev/admin`
   - ランキング：`https://it-casino.pages.dev/ranking`

### 修正したら公開しなおす
```
npm run cf:deploy
```

### そのほか
| やりたいこと | コマンド / 操作 |
|---|---|
| 管理画面のパスワードを変える | `npm run cf:password`（そのあと `npm run cf:deploy`） |
| 手元で Cloudflare 版を試す | `.dev.vars` に `ADMIN_PASSWORD=好きなパスワード` と書いて `npm run cf:dev` → http://localhost:8788 |
| 動作確認 | `npm run smoke -- https://it-casino.pages.dev 管理パスワード` |
| 本番前にテストデータを消す | 管理画面 →「バックアップ / リセット」 |
| 学祭が終わって閉鎖する | Cloudflare のダッシュボード → Workers & Pages → it-casino → Settings → Delete（削除） |

- 管理画面のパスワードを設定しないと、管理画面にはログインできません（ネットに出るので初期パスワードは使えないようにしています）
- バックアップは管理画面の「全データをJSONで保存」で各日の終わりに保存してください
- Cloudflare の無料枠（1日10万リクエスト程度）で2日間の学祭なら足ります。料金や無料枠は変わることがあるので公式サイトでも確認してください
- `it-casino` という名前がほかの人に使われていた場合は、`wrangler.toml` の `name` と `package.json` の `cf:password` の `it-casino` を別の名前に変えてから `npm run cf:setup`
- ネット公開版ではズル対策をしていません（ゲーム結果はブラウザから送っています）

## 運用

- **VRボーナス**：VR体験後、管理画面で名前を検索して「VRボーナス +50」（1人1日1回）
- **やり直し**：チップが0になったら、ロスカット画面の「最初からやり直す」で初期チップから再スタート（回数制限なし。最高記録はランキングに残る）
- **残高修正**：「増減する」「この値に設定」。履歴の「取消」で誤操作を打ち消せます（取消も履歴に残ります）
- **二重利用防止**：同じ名前では2台で同時に遊べません。端末を放置した場合は90秒で自動解除、急ぐときは管理画面の「ロック解除」
- **無操作タイムアウト**：90秒操作がないと待機画面に戻ります（ゲーム中だった場合は「負け」扱い）
- **ロスカット**：所持チップが0になると発動。最高記録はランキングに残ります
- **かんたんモード**：子ども向け。レバレッジ×1固定（登録時・ゲーム選択画面・管理画面で切替）

### バックアップ

- サーバーは10分ごとに `data/backups/` へ自動バックアップ（最新50個を保持）
- **各日の終了時**：USBメモリを挿して `backup-to-usb.bat` をダブルクリック → ドライブ文字を入力
  （または管理画面 →「DBファイルをダウンロード」）
- 復元：サーバーを止め、バックアップの `.db` を `data/casino.db` に上書き（`casino.db-wal` / `casino.db-shm` があれば削除）して再起動

## 設定（config.json）

数値はすべて `config.json` で変更できます（変更後はサーバー再起動）。当日用の上書きは `config.local.json` に同じ形で書きます。

| 項目 | 場所 |
|---|---|
| 初期チップ・最低賭け額・レバレッジ・VRボーナス | `chips` |
| 無操作タイムアウト・端末ロック解除時間 | `session` |
| ピンボールの目標スコア・倍率・キー割り当て | `games.pinball` |
| 各ゲームの倍率・デッキ数・ハンド数など | `games.*` |
| ゲームの公開/非公開 | `games.*.enabled` |
| NGワード | `ngWords` |

### ピンボールの目標スコア調整

初期値は「目標 2,000 / 高得点 5,000 / 超高得点 9,000」です。テストプレイ後に調整してください。
台の物理とスコア分布はシミュレーションで確認できます：

```sh
node scripts/pinball-sim.js 40   # 自動でフリッパーを動かすボットに遊ばせてスコア分布を表示
node scripts/pinball-check.js    # 発射とフリッパーの基本動作チェック
```

## ルールの細かい決め

仕様書で決まっていない部分は次のようにしています（必要なら config やコードで変更）。

- **ログイン**：名前＋パスワード（半角英数字4〜16文字、`account` で変更可）。パスワードは暗号化（scrypt）して保存。5回続けて間違えると1分間ログインできない。入力欄はブラウザの「パスワードを保存」が出ないようにしている
- **途中終了**：ゲーム中に無操作タイムアウト・端末の切り替えがあった場合、そのゲームは「−1（負け）」で精算
- **賭け額**：最低10チップ。所持チップが10未満のときは全額まで賭けられる
- **ブラックジャック**：ダブルダウンは倍率×2（負けも×2）。配られた時点で両者のBJを判定。スプリット・サレンダー・インシュランスなし
- **バカラ**：プレイヤー/バンカーに賭けてタイになった場合は**引き分け（±0）**（実際のカジノと同じ）。
  仕様書どおり「外れ −1」にするなら `games.baccarat.tiePushesPlayerBanker` を `false`
- **ホールデム**：バイイン＝賭けチップ、CPUも同額。ブラインドは賭けチップの5%/10%。CPUはモンテカルロで勝率を見積もって判断
- **大富豪**：ジョーカー1枚（他の数字の代わりにもなる）。開始前に 革命・8切り・11バック・しばり・スペ3返し・階段・5飛ばし を選べる（おすすめは革命と8切り）。階段は「いちばん弱いカード同士」で比べる。あなたの順位が決まった時点で終了
- **ピンボールの引っかかり対策**：ボールが2秒ほとんど動かなければ自動で弾き出し、それでも抜けなければ中央に戻す。プレイヤーもスペースで「台をゆらす」ことができる
- **こいこい**：こいこい後に相手があがると相手の点が2倍。流局は0点。親は月ごとに交代
- **制限時間**：ブラックジャック・ホールデム・大富豪・こいこいは1手ごとに制限時間（時間切れは自動で無難な手）

## 開発

```sh
npm install
npm start        # http://localhost:3000
npm test         # API・役判定・各ゲームのルールの単体テスト
npm run cf:dev   # Cloudflare版を手元で動かす（http://localhost:8788）
npm run vendor   # node_modules から public/vendor にライブラリをコピーし直す
```

```
server/          PC版のサーバー（Express）
  core/          APIの本体（PC版とCloudflare版で共通）：api.js / schema.js / accounts.js / db-node.js / db-d1.js
functions/       Cloudflare Pages Functions（/api/* を core に渡すだけ）
public/          ブラウザ側（index.html ゲーム端末 / admin.html 管理 / ranking.html）
  js/lib/        ゲームのルール（サーバー・テストと共通）
  js/games/      各ゲームの画面
  vendor/        Matter.js（ローカル同梱）
scripts/         バックアップ・ピンボール調整用
test/            node:test の単体テスト
docs/            当日用の資料
```

- チップの増減はすべてサーバーで計算し、`transactions` テーブルに記録します。ブラウザからは「ゲーム結果」（スコアや勝敗）だけを送ります
- 将来の通信対戦（WebSocket）は未実装です
